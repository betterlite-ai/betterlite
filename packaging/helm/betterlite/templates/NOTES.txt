Reminders:
  - Sensitive values come from Secret references only. Before installing, set:
      - masterKey.secretName                                   (Secret with the proxy master key)
      - database.writer.{host,port,dbname}                     (writer connection pieces)
      - database.writer.passwordSecret.{name,usernameKey,passwordKey}
                                                               (Secret holding the writer DB username + password)
      - database.writer.useIAMAuth: true                       (optional; sets IAM_TOKEN_DB_AUTH=true and omits
                                                                DATABASE_PASSWORD so the proxy mints the URL from
                                                                an IAM token at startup)
      - database.reader.host                                   (optional; enables read-replica routing, and
                                                                database.reader.dbname is required when set)
      - database.reader.useIAMAuth: true                       (optional; requires database.writer.useIAMAuth: true)
      - redis.passwordSecret.name                              (optional; set when redis.host needs auth)
      - redis.cluster: true                                    (optional; sets REDIS_CLUSTER_NODES from
                                                                redis.host and redis.port)
  - Per-component extras (gateway / backend / ui):
      - {component}.extraEnv / envConfigMaps / envSecrets      (the latter two are lists of resource names)
      - {component}.logLevel                                   (renders as LITELLM_LOG)
      - gateway.config.proxy_config                            (rendered into a ConfigMap and mounted at
                                                                /etc/betterlite/config.yaml; the gateway reads it
                                                                through CONFIG_FILE_PATH)
      - {component}.pdb.{enabled,minAvailable,maxUnavailable}  (per-component PodDisruptionBudget)
      - {component}.topologySpreadConstraints                  (standard k8s list, e.g. spread across zones)
  - Enable ingress.enabled=true to dispatch / to the ui, the gateway data-plane prefixes to the gateway
    and the catch-all to the backend.
