Database tests run against one PostgreSQL server per test run, and each test gets its own database copied from a template (Max). CI keeps its postgres:16.6 service. Locally, nextest's setup script tools/postgres-fixture/nextest-postgres.sh starts the same pinned postgres:16.6 image on a random port and removes it when the run ends; without docker and without POSTGRES_TEST_URL it exits 0, so only the database tests fail. The fixture builds each schema (the LiteLLM baseline, the baseline with daily usage, the dashboard schema) once per server into a template database and copies it per test with CREATE DATABASE ... TEMPLATE, about 80 ms against about 140 ms for running the baseline and 3.6 s for starting a testcontainers server (measured 11-17).
