A failed CI run on a draft PR reaches the worker with the same detail as a fix round after the PR opens (Max). early-pr.sh used to write only the first two FAIL lines into the journal's ci-failures file, so a worker on a draft fixed code it had never seen fail: in the night to 11-18 review rounds ran out on branches that never compiled (B693 twice, B8910), and B693's draft had 7 failed runs in 95 minutes. ci-failure.sh now downloads the run's gate logs into the worktree's target/ci-logs/<run> and prints up to 60 FAIL and panic lines, a failed mutants baseline, and the missed and timed-out mutants. The land's fix round and early-pr.sh both call it.
