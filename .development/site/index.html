Porting LiteLLM to Rust

betterlite rewrites LiteLLM in Rust under the MIT license. Coding agents build it one task at a time, and a task merges once its gate passes. This page reads the task list on main and is rebuilt after every merge.

By milestone

Done: merged, or closed without code. In review: a task pull request is open. Ready: the task file is written and every dependency is merged. Waiting: a dependency is not merged yet. No task file: the planner has not written it yet.
